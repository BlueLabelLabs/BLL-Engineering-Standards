# The golden path

> **Generated from `packs/`. Do not edit this file.**
> Change the pack in the blueprint repository and regenerate. Hand edits are

What we build on, and why: cloud providers, compute, datastores, frameworks,
auth, observability, and the AI stack.

The [guidelines](../guidelines/README.md) are the hard rules, the things that must
be true. The golden path is the layer above: the defaults we reach for when nothing
forces a different choice. Departing from it is normal and expected, and it comes
with a recorded reason ([ARC-003](../guidelines/README.md#arc--architecture)).

## How these compose

More than one page applies to any real project. Universal is always on, one provider
page applies, and one or more workload pages apply on top. Where two disagree, the
more specific wins: client constraints over compliance, compliance over provider,
provider over universal.

## Why this is generated

These pages render from the rule packs inside BlueLabel's architecture skills, the
same source our agents read when they design a system. The previous version of these
standards went stale because a human had to remember to update it. Now a change to a
pack opens a pull request here, and the documents cannot drift from what the agents
actually apply.
