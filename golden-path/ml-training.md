## Preferences

- Deep-learning framework: **PyTorch**.
- Image detection / computer vision: **YOLO** as the starting point.
- Classical / tabular ML: **scikit-learn** and **XGBoost**.
- Pretrained models: pull from **HuggingFace**.
- Experiment tracking, pipelines, and model registry: **MLflow**.
- Data labeling: **Label Studio** on a BlueLabel self-hosted instance.
- Inference hosting: **Amazon SageMaker** (AWS) / **Azure ML** (Azure) — real-time endpoints.
- Training compute: local or cloud GPU.

## Selection guidance

- Pick the approach by problem: **YOLO** for image detection; **scikit-learn/XGBoost** for tabular/classical; **PyTorch** for custom deep learning; **HuggingFace** for a pretrained base to fine-tune.
- Serve via the provider's managed ML platform — **SageMaker on AWS, Azure ML on Azure** (composes with the provider pack); inference is real-time by default.
- The application/API that consumes the model follows the `server-side` pack (FastAPI REST); auth, monitoring, and data follow `universal-baseline`.
- Recommended artifacts: training-pipeline diagram, dataset-lineage doc, model card, eval-report spec, inference-deployment topology.
