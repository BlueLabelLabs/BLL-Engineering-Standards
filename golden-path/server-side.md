## Preferences

- Backend framework: **Python + FastAPI** by default; **.NET / ASP.NET Core (latest, C#)** for Windows / SQL Server shops; **Node / TypeScript / Express** only as a last resort.
- API contract: **versioned**; **offset/limit pagination**; a **standard error format with error codes**.

## Selection guidance

- Switch off Python to **.NET / ASP.NET Core** when the client is a Windows / SQL Server shop; **Node/TS/Express** only when neither is possible.
- Background work → durable queue + serverless processor: **SQS + Lambda** on AWS, **Service Bus / Storage Queue + Azure Function** on Azure (composes with the provider pack).
- Service conventions (project structure, validation, testing, packaging) are below the architecture barrier — see `references/conventions/server-side.md`.
